1. TỔNG QUAN HỆ THỐNG
================================================================================

Hệ thống này được thiết kế để chuyển đổi dữ liệu Q&A đơn giản thành các cuộc 
hội thoại multi-turn (5-7 lượt) dựa trên trạng thái tâm lý và chiến lược 
phản hồi. Sử dụng notebook đơn giản để tạo dataset phong phú cho việc 
fine-tuning chatbot về sức khỏe tâm thần.

2. CẤU TRÚC DỮ LIỆU ĐẦU VÀO
================================================================================

File CSV cần có các cột sau:
- question: Câu hỏi của người dùng
- answer: Câu trả lời của assistant  
- mental_state: Trạng thái tâm lý (Depression, Anxiety, Stress, Suicidal, Bipolar, Normal)
- confidence: Độ tin cậy dự đoán trạng thái
- sentiment_intensity: Cường độ cảm xúc (0-3)
- conf_intensity: Độ tin cậy cường độ
- sentiment_strategy: Chiến lược phản hồi (Encourage, Validate, Explore, Empathize)
- conf_strategy: Độ tin cậy chiến lược

3. SỬ DỤNG CONFIDENCE INTENSITY
================================================================================

3.1. Ý Nghĩa Của Confidence Intensity:
- conf_intensity: Độ tin cậy của việc dự đoán cường độ cảm xúc (0-1)
- Giá trị cao (>0.8): Dự đoán cường độ rất chính xác
- Giá trị trung bình (0.5-0.8): Dự đoán cường độ khá chính xác
- Giá trị thấp (<0.5): Dự đoán cường độ không chắc chắn

3.2. Cách Sử Dụng Trong Logic Tạo Conversation:

a) Điều Chỉnh Số Lượt Hội Thoại:
```python
# Dựa trên confidence intensity để quyết định số lượt
if conf_intensity >= 0.8:
    num_turns = random.randint(6, 8)  # Nhiều lượt hơn cho dự đoán chính xác
elif conf_intensity >= 0.5:
    num_turns = random.randint(5, 7)  # Số lượt trung bình
else:
    num_turns = random.randint(3, 5)  # Ít lượt hơn cho dự đoán không chắc chắn
```

b) Điều Chỉnh Chiến Lược Phản Hồi:
```python
# Kết hợp confidence intensity với sentiment strategy
if conf_intensity >= 0.8:
    # Sử dụng chiến lược gốc với độ tin cậy cao
    strategy = row['sentiment_strategy']
elif conf_intensity >= 0.5:
    # Thêm chiến lược "Explore" để tìm hiểu thêm
    if row['sentiment_strategy'] != 'Explore':
        strategy = 'Explore'
    else:
        strategy = row['sentiment_strategy']
else:
    # Sử dụng chiến lược an toàn "Validate"
    strategy = 'Validate'
```

c) Điều Chỉnh Cường Độ Phản Hồi:
```python
# Điều chỉnh cường độ phản hồi dựa trên confidence
if conf_intensity >= 0.8:
    # Phản hồi mạnh mẽ và trực tiếp
    response_templates = strong_response_templates
elif conf_intensity >= 0.5:
    # Phản hồi cân bằng
    response_templates = balanced_response_templates
else:
    # Phản hồi nhẹ nhàng và cẩn thận
    response_templates = gentle_response_templates
```

3.3. Lọc Dữ Liệu Theo Confidence:
```python
# Chỉ sử dụng dữ liệu có độ tin cậy cao
high_confidence_data = data[data['conf_intensity'] >= 0.7]

# Hoặc tạo trọng số cho từng sample
data['weight'] = data['conf_intensity'] * data['confidence']
```

3.4. Tạo Templates Theo Confidence Level:
```python
# Templates cho confidence cao
high_conf_templates = {
    'Depression': [
        "Tôi thấy rõ ràng bạn đang trải qua trầm cảm. Hãy chia sẻ thêm.",
        "Dựa trên những gì bạn mô tả, đây là dấu hiệu của trầm cảm.",
        "Tôi tin chắc rằng bạn cần được hỗ trợ chuyên môn."
    ]
}

# Templates cho confidence thấp
low_conf_templates = {
    'Depression': [
        "Có vẻ như bạn đang gặp khó khăn. Bạn có thể chia sẻ thêm không?",
        "Tôi muốn hiểu rõ hơn về tình huống của bạn.",
        "Hãy cùng tìm hiểu xem điều gì đang xảy ra."
    ]
}
```
